# Asset licenses and approval

The LMQ mark and procedural hero sculpture are original project assets. Manrope Variable and Barlow Condensed fonts are distributed under SIL OFL via @fontsource packages (license included in each package). Lucide icons use ISC. No athlete photos, human anatomy meshes or exercise animations are included.

Model catalog records require URL, author, source URL, license, attribution, named region map and `review_status = approved`. Exercise clips additionally require a reviewer and review date. Do not publish an approval without a qualified review. Browser loading accepts HTTPS and same-origin root paths only; no script/data URL assets.

Nutrition: no food macro values are seeded. Users must supply quantities and values from a label or a documented composition source. Local food suggestions are names, not database nutrition claims.

The new championship-inspired theme retains original LMQ artwork with crimson/gold lighting. No official Olympia logos or athlete photographs are copied. Supplied PDF program text is transformed into source-linked structured data at the user’s request; original PDFs and their images are not included in public assets.
